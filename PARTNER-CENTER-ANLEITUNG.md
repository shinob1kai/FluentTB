## 🎯 Schritt 15: Hinweise für Zertifizierung

### Testhinweise für Microsoft

```
TESTANLEITUNG FÜR ZERTIFIZIERER:

1. INSTALLATION:
   - App aus Package installieren
   - Keine Administratorrechte erforderlich
   - .NET 8.0 Runtime ist im Package enthalten

2. GRUNDLEGENDE TESTS:
   - Starten Sie FluentTB
   - Systemtray-Icon sollte erscheinen
   - Klicken Sie auf "Settings" im Systemtray-Menü
   - Hauptfenster öffnet sich

3. FUNKTIONSTEST:
   - Ändern Sie "Transparency" Slider
   - Taskleiste sollte transparenter werden
   - Ändern Sie "Color" (Farbe auswählen)
   - Taskleiste sollte Farbe ändern
   - Alle Änderungen sind in Echtzeit sichtbar

4. MULTI-MONITOR (falls verfügbar):
   - Mit mehreren Monitoren testen
   - Jeder Monitor kann separate Einstellungen haben
   - Dropdown-Menü "Monitor" wechseln

5. STABILITÄT:
   - App läuft stabil im Hintergrund
   - Windows-Neustart: Einstellungen bleiben erhalten
   - Taskleiste kehrt zu Windows-Standard zurück, wenn App beendet wird

6. DATENSCHUTZ:
   - Keine Internetverbindung erforderlich (außer optionaler Update-Check)
   - Keine Datensammlung
   - Lokale Konfiguration: %LOCALAPPDATA%\FluentTB\

   - "Dynamic Mode" ist derzeit deaktiviert (in UI ausgeblendet)
```
